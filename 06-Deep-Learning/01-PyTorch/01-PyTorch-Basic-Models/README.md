# 🤖 02 - PyTorch Basic Models

Welcome to the PyTorch Basic Models directory! This folder contains end-to-end neural network implementations trained on simple, synthetic, or toy datasets.

## 🎯 Goal
Instead of isolating concepts, every notebook in this sub-module is a complete, working model designed to apply the full PyTorch pipeline from scratch:
* **Data Prep:** Creating synthetic data or loading lightweight datasets with `torch.utils.data`.
* **Architecture:** Subclassing `nn.Module` and defining the `forward()` pass.
* **Optimization:** Setting up Loss Functions and Optimizers (`Adam`, `SGD`).
* **Execution:** Writing explicit training loops, evaluation steps (`torch.inference_mode()`), and tracking metrics.
* **Persistence:** Saving and loading model parameters using `state_dict()`.
