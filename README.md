# AI & Machine Learning Engineering Portfolio

*Note:* This is an actively maintained repository tracking my progression from foundational programming to applied deep learning. I continuously update this space with custom neural network architectures, optimized pipelines, and feature engineering techniques.

## 📂 Repository Structure

This repository is organized sequentially to track my engineering milestones. Navigate to any directory to explore the specific notebooks, data pipelines, and project architectures:

*   **[01-Python-Basics](./01-Python-Basics)** 🐍
    *   Foundations of Python programming, core data types, control flow, functions, and scripting.
*   **[02-OOPs](./02-OOPs)** 🏗️
    *   Object-Oriented Programming concepts (Classes, Inheritance, Polymorphism, and Encapsulation) applied to scalable code design.
*   **[03-Numpy](./03-Numpy)** 🧮
    *   Scientific computing, multidimensional array manipulation, matrix math, and advanced broadcasting mechanics.
*   **[04-EDA](./04-EDA)** 📊
    *   Exploratory Data Analysis pipelines, data cleaning, handling missing values, and visual storytelling using Pandas, Matplotlib, and Seaborn.
*   **[05-Machine-Learning](./05-Machine-Learning)** ⚙️
    *   End-to-end predictive modeling workflows. Features custom Scikit-Learn pipelines, hyperparameter tuning (`GridSearchCV`/`RandomizedSearchCV`), ensemble methods, and unsupervised learning (K-Means, DBSCAN, PCA, t-SNE).
    *   *Featured Projects:* Customer Segmentation (Mall Customers), Dimensionality Reduction (MNIST Digits), Kaggle House Prices, and US Stock Returns Prediction.
*   **[06-Deep-Learning](./06-Deep-Learning)** 🧠
    *   Deep learning architectures, GPU acceleration (CUDA), and custom vision pipelines (`torchvision`). Focuses heavily on understanding the mechanics behind mathematical bottlenecks and regularization.
    *   *Featured Projects:* Breast Cancer Binary Classification, MNIST Multiclass Classification, spatial feature extraction limitations (Food-101), and a comprehensive benchmarking study comparing Custom CNNs against fine-tuned ResNet-18 Transfer Learning on the Intel Image Classification dataset.

## 🛠️ Core Tech Stack

*   **Languages:** Python
*   **Data & Math:** NumPy, Pandas
*   **Machine & Deep Learning:** Scikit-Learn, LightGBM, XGBoost, PyTorch, `torchvision`
*   **Data Visualization:** Matplotlib, Seaborn
*   **Environments:** Jupyter Notebook, Google Colab, Git
